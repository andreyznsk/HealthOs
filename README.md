# HealthOS

HealthOS — приватный репозиторий нормализованной медицинской истории.

## Архитектура MVP

Исходный документ (PDF / фото / скрин)
→ локальный AI-агент
→ структурированный Markdown
→ private GitHub repository
→ ChatGPT Project
→ анализ динамики
→ Google Sheets `HealthOS_Data`

## Что хранится в Git

В Git хранятся только нормализованные текстовые данные и отчеты:

- лабораторные анализы;
- обследования;
- заключения врачей;
- медицинская история;
- лекарства;
- аналитические отчеты.

Исходные PDF, изображения и скриншоты могут храниться отдельно локально или в Google Drive.

## Главный принцип

1. Оригинальный документ — первоисточник.
2. Markdown — точная нормализованная копия фактов.
3. Google Sheets — структурированные данные для анализа.
4. Аналитические выводы не должны смешиваться с исходными медицинскими фактами.
