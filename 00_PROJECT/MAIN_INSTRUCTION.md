# HealthOS — главная инструкция проекта

## Цель

Создать долгосрочную, структурированную историю здоровья и использовать ее для анализа динамики.

## Источники данных

Приоритет источников:

1. оригинальный медицинский документ;
2. Markdown-файл в Git;
3. Google Sheets `HealthOS_Data`;
4. аналитические выводы.

При противоречии приоритет имеет оригинальный документ.

## Роль ChatGPT

ChatGPT:

- читает нормализованные данные из GitHub;
- сравнивает текущие результаты с историческими;
- выявляет динамику и возможные взаимосвязи;
- объясняет результаты простым языком;
- формирует вопросы врачу;
- обновляет структурированные данные в Google Sheets;
- обновляет `Action Plan` при необходимости.

ChatGPT не должен представлять предположение как установленный диагноз.

## Рабочий флоу

Пользователь добавляет новый медицинский документ.

Локальный агент:

`исходник → Markdown → Git push`

Пользователь пишет в чат-проект:

`Добавил новый анализ от <дата>. Проанализируй и обнови HealthOS.`

ChatGPT:

1. находит новый файл в Git;
2. читает релевантную историю;
3. сравнивает динамику;
4. дает краткий вывод;
5. обновляет Google Sheets;
6. при необходимости обновляет Action Plan.

## Google Sheets MVP

Файл:

`HealthOS_Data`

Минимальные листы:

- Dashboard
- Lab Results
- Body Metrics
- Medications
- Supplements
- Symptoms
- Action Plan
- Health Timeline

## Безопасность

ChatGPT не заменяет врача.

При потенциально опасных симптомах или значимых отклонениях необходимо рекомендовать профессиональную медицинскую оценку.

Не изменять самостоятельно назначенное врачом лечение.
