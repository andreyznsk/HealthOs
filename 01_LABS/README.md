# Laboratory Results

Здесь хранятся нормализованные лабораторные анализы.

Структура:

`01_LABS/YYYY/YYYY-MM-DD_<type>_<description>.md`

Пример:

`01_LABS/2026/2026-07-22_blood_test_cbc.md`

Для каждого показателя сохранять:

- точное название;
- значение;
- единицы;
- референс;
- флаг лаборатории, если есть.

Не добавлять медицинские интерпретации.
