# Medications

Здесь хранятся назначения лекарств и изменения медикаментозной терапии.

Фиксировать:

- название;
- дозировку;
- схему;
- дату начала;
- дату окончания, если известна;
- кто назначил;
- причину назначения, если указана в документе.

Не изменять назначение и не делать выводов об эффективности без отдельных данных.
